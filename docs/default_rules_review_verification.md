# 默认分类与规则回顾：补丁验证

日期：2026-09-08。分支：`feat/protocol-assisted-qc`。作者：zhenzong。

本记录仅描述合成数据与本地程序验证；未连接工作站影像，不代表真实队列验收。
没有重新扫描或转换全队列，没有执行真实 BIDS 归档。

## 行为变化

- 单个序列名称同时包含 T1 和 FLAIR 时归为 T1，不要求相邻或顺序固定。
- CT、TOF、MRA、DWI、b0、b1000 默认非目标；全部序列入口仍可找回和人工纠错。
- 唯一影像候选可自动完成识别；同名重扫、普通 T1 与 T1-FLAIR 并存仍需比较。
- 已保存人工决定优先。升级备份旧识别状态，只保留实际完成的患者/模态，部分排除组继续识别。
- 常驻规则回顾支持纳入/优先级、排除、逐患者未找到、重新人工识别的查询和定点撤销。
- 撤销只移除当前指定规则，不恢复旧规则，不改逐影像质量记录，也不在网页中修改 BIDS。
- 恢复默认与保留待定分别可选；质量阶段撤销须明确确认返回识别阶段。

## 工作站更新

先在网页保存未提交的编辑，再用 Ctrl+C 停止阅片器。保留已有本地配置，在当前项目目录运行：

```bash
git pull --ff-only origin feat/protocol-assisted-qc &&
python qc_assist.py catalog --config config/config.nifti.local.yaml &&
python qc_viewer.py --config config/config.nifti.local.yaml --no-browser
```

不要重建 inventory、转换影像或复制旧 BIDS。新版 `catalog` 读取已有清单和人工记录，
自动备份迁移前识别状态，报告人工完成、自动唯一识别、多候选、未知待识别、默认跳过数量。
实际减少的工作量以工作站新统计为准；本地合成计数不用于推算真实人数。

手动打开阅片地址并强制刷新旧页面缓存。左侧“规则回顾 / 撤销”可查看已完成组的规则，
勾选后先预览，再确认撤销。旧人工 FLAIR 规则会优先于新的 T1-FLAIR 默认规则，
需要时撤销相应人工规则；逐影像人工记录不受模板撤销覆盖。

先核对少量代表病例与已有人工记录，再继续全队列识别。全部识别完成后仍须进入独立
质量阶段；本补丁不新增质量通过，不替代人工质量确认或单独 `--apply`。
